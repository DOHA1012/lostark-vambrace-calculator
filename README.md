# 로스트아크 완갑 전투력 계산기

캐릭터의 현재 스펙과 완갑 강화 수치를 넣으면, 완갑을 장착하기 전과 후의 기본 공격력과 전투력 변화를 계산하는 웹 도구입니다.

**바로 쓰기:** https://doha1012.github.io/lostark-vambrace-calculator/

## 기능

- **캐릭터 불러오기** — 공식 Open API에서 프로필, 장비, 아바타, 보석, 아크 패시브 정보를 불러와 기본 공격력, 주스탯, 무기 공격력과 비율 보정값을 채웁니다. 최근 조회한 캐릭터를 다시 고를 수 있습니다.
- **직접 입력** — API 없이 값을 손으로 넣거나, 불러온 값과 아바타, 무기 공격력, 보석 같은 비율 보정값을 고칠 수 있습니다.
- **완갑 수치 설정** — 공개된 21강 수치를 기본값으로 두고 주스탯, 무기 공격력, 기본 공격력, 공격력 %를 바꿀 수 있습니다.
- **계산 과정 공개** — 현재 전투력 상수에서 최종 증가량까지 9단계 계산을 숫자와 함께 펼쳐 볼 수 있습니다.

## 계산 기준

[로스트아크 인벤에 공개된 완갑 전투력 증가량 공식](https://m.inven.co.kr/board/lostark/6271/3790814)을 따릅니다.

## 참고

- 캐릭터 불러오기에는 본인의 Open API 키가 필요합니다. 키는 브라우저 localStorage에만 저장되고 공식 API로만 전송됩니다.
- 결과는 공식에 따른 추정치이며 실제 게임 수치와 다를 수 있습니다.
